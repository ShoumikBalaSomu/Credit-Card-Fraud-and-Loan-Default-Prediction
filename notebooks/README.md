### Running the Notebook
You can run this notebook in two ways:

1. **Google Colab (Zero-Setup Cloud Execution):**
   Click the **Open in Colab** badge above or visit:
   `https://colab.research.google.com/github/ShoumikBalaSomu/ML-Project-Group-08/blob/main/FinRisk_ML_Group08.ipynb`

2. **Local Jupyter Environment:**
   ```bash
   jupyter notebook FinRisk_ML_Group08.ipynb
   ```
   Or execute headless from the command line:
   ```bash
   jupyter nbconvert --to notebook --execute --inplace FinRisk_ML_Group08.ipynb
   ```
