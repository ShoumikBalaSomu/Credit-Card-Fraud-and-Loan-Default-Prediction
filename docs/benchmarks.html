1. Non-Linear Feature Interactions

Logistic Regression failed completely on fraud (PR-AUC 0.1984) because fraud boundaries depend on complex conjuncts of Haversine distance, transaction amount, and categorical merchant risk. Tree ensembles capture these interactions naturally without feature manual interaction explosion.

2. Probability Blending Advantage

Soft-voting probability blending between CatBoost and LightGBM outperformed all individual models on fraud (PR-AUC 0.8398 vs 0.8364), while Random Forest + LightGBM reached PR-AUC 0.6259 on loan default risk, demonstrating variance reduction through algorithmic diversity.

3. Post-Hoc Threshold Superiority

Post-hoc expected loss thresholding ($p^*$) outperformed heuristic SMOTE resampling and class-weighting across every model family. Cost-weighted training distorted decision borders, whereas empirical threshold search preserves true ranking while minimizing economic loss.
