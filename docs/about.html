2. Executive Summary

Cost-sensitive and explainable machine learning research for asymmetric financial risk.

1. Project Motivation & Asymmetric Risk

In financial systems, conventional accuracy and symmetric metrics fail due to extreme class imbalance (0.58% fraud prevalence, 12.30% loan default prevalence) and heavily asymmetric misclassification costs. Missing a fraudulent transaction or defaulting borrower (False Negative) incurs severe capital loss compared to the nominal operational friction of reviewing a legitimate customer (False Positive). We establish strict chronological holdout splits, cost-optimal Bayesian threshold tuning, and game-theoretic SHAP explainability to maximize realized financial savings.

2. Key Empirical Findings & Cost Reductions

  • Credit Card Fraud Detection (Task A): CatBoost and Ensemble Blend achieve state-of-the-art PR-AUC (0.8398). Calibrating the decision threshold to the cost-optimal cutoff \( p^* = 0.023 \) reduces total misclassification losses from $21,720 to $12,160, delivering a 44.01% financial cost reduction over standard 0.50 thresholding.
  • Loan Default Prediction (Task B): Random Forest and Ensemble Blend achieve leading PR-AUC (0.6259) and ROC-AUC (0.9135). Shifting threshold cutoff to \( p^* = 0.142 \) cuts default write-downs from $7.09M to $1.89M, securing 73.41% financial savings.
  • Real-Time Production SLA: Single-sample inference latency is benchmarked at 0.0149 ms per transaction (exceeding 67,000 inferences/sec), comfortably satisfying mission-critical payment gateway sub-10ms SLA requirements.

3. Explainability & Regulatory Compliance

Under the Equal Credit Opportunity Act (ECOA 12 CFR § 1002.9) and Fair Credit Reporting Act (FCRA), adverse financial decisions mandate adverse action notices with principal reason codes. We integrate TreeSHAP waterfall decompositions to generate deterministic, local attribution rankings (transaction amount, spatial Haversine distance, income-to-experience ratios) for every automated decline decision.

3. Step-by-Step Reproducibility Protocol

Fully deterministic execution verified with master seed 42 on Fedora Linux.

Step 1: Clone Repository and Setup Environment

git clone https://github.com/ShoumikBalaSomu/ML-Project-Group-08.git
cd ML-Project-Group-08
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

Step 2: Run End-to-End Pipeline

python scripts/run_all.py --phase all

Executes training across all 6 model architectures, computes optimal Bayesian thresholds, generates diagnostic curves and SHAP beeswarms, and writes 5 local case studies into reports/case_studies.md.

Step 3: Run Verification Test Suite (35 Invariants)

pytest -v tests/

Verifies 35 automated invariants: lack of lookahead leakage, cost matrix arithmetic, Population Stability Index (PSI) drift detection, 80% four-fifths fairness rule, Shapley efficiency properties, and sub-10ms inference SLAs.
