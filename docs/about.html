2. বাংলা সারসংক্ষেপ (Executive Summary in Bengali)

আর্থিক ঝুঁকি বিশ্লেষণে খরচ-সংবেদনশীল এবং ব্যাখ্যাযোগ্য মেশিন লার্নিং গবেষণা

১. প্রকল্পের পটভূমি ও মূল উদ্দেশ্য

আর্থিক খাতে মেশিন লার্নিং মডেল ব্যবহারের ক্ষেত্রে সাধারণ অ্যাকুরেসি (Accuracy) বা সুষম মেট্রিক সম্পূর্ণ অকার্যকর। কারণ ক্রেডিট কার্ড প্রতারণায় হার মাত্র ০.৫৮% এবং ঋণ খেলাপি হার ১২.৩০%। তদুপরি, একটি প্রতারণামূলক লেনদেন বা ঋণ খেলাপি ধরতে না পারার আর্থিক ক্ষতি (False Negative) একটি বৈধ লেনদেন যাচাই করার খরচের (False Positive) চেয়ে বহুগুণ বেশি। এই গবেষণায় আমরা কঠোর সময়ভিত্তিক বিভাজন (Chronological Split), কস্ট-অপ্টিমাল থ্রেশহোল্ড টিউনিং এবং গেম-তাত্ত্বিক SHAP প্রয়োগের মাধ্যমে সর্বোচ্চ আর্থিক সঞ্চয় নিশ্চিত করেছি।

২. মূল গবেষণার ফলাফল ও আর্থিক সঞ্চয়

  • ক্রেডিট কার্ড প্রতারণা প্রতিরোধ (Task A): CatBoost এবং Ensemble Blend সর্বোচ্চ PR-AUC (০.৮৩৯৮) অর্জন করেছে। সনাতন ০.৫০ থ্রেশহোল্ডের পরিবর্তে অপ্টিমাল কাটঅফ \( p^* = 0.023 \) নির্ধারণ করে মোট আর্থিক ক্ষতি $২১,৭২০ থেকে কমিয়ে $১২,১৬০-এ নামিয়ে আনা সম্ভব হয়েছে, যা ৪৪.০১% আর্থিক সাশ্রয় নিশ্চিত করে।
  • ঋণ খেলাপি পূর্বাভাস (Task B): Random Forest এবং Ensemble Blend সর্বোচ্চ PR-AUC (০.৬২৫৯) এবং ROC-AUC (০.৯১৩৫) অর্জন করেছে। সিদ্ধান্ত থ্রেশহোল্ড \( p^* = 0.142 \)-তে নামিয়ে এনে ঋণ খেলাপি ক্ষতি $৭.০৯ মিলিয়ন থেকে $১.৮৯ মিলিয়নে নামিয়ে আনা হয়েছে, যা ৭৩.৪১% আর্থিক সাশ্রয় নিশ্চিত করে।
  • রিয়েল-টাইম সক্ষমতা: প্রতি লেনদেনে ইনফারেন্স লেটেন্সি মাত্র ০.০১৪৯ মিলি-সেকেন্ড (প্রতি সেকেন্ডে ৬৭,০০০+ লেনদেন যাচাই সম্ভব), যা পেমেন্ট গেটওয়ের সাব-১০ms এসএলএ শর্তের সাথে সম্পূর্ণ সঙ্গতিপূর্ণ।

৩. ব্যাখ্যাযোগ্যতা এবং নিয়ন্ত্রক বিধিমালা

ইউএস ইকুয়াল ক্রেডিট অপরচুনিটি অ্যাক্ট (ECOA) এবং ফেয়ার ক্রেডিট রিপোর্টিং অ্যাক্ট (FCRA) বিধিমালা অনুযায়ী প্রতিটি প্রত্যাখ্যানের সুনির্দিষ্ট কারণ প্রকাশ করা বাধ্যতামূলক। আমরা TreeSHAP এবং ওয়াটারফল ডায়াগ্রামের মাধ্যমে প্রতিটি সিদ্ধান্তের পেছনে শীর্ষ বৈশিষ্ট্যসমূহ (লেনদেনের পরিমাণ, ভৌগোলিক দূরত্ব, ঋণ-আয়ের অনুপাত) স্বয়ংক্রিয়ভাবে উপস্থাপনের পাইপলাইন তৈরি করেছি।

3. Step-by-Step Reproducibility Protocol

Fully deterministic execution verified with master seed 42 on Fedora Linux.

Step 1: Clone Repository and Setup Environment

git clone https://github.com/ShoumikBalaSomu/ML-Project-Group-08.git
cd ML-Project-Group-08
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

Step 2: Run End-to-End Pipeline

python scripts/run_all.py --phase all

Executes training across all 6 model architectures, computes optimal Bayesian thresholds, generates diagnostic curves and SHAP beeswarms, and writes 5 local case studies into reports/case_studies.md.

Step 3: Run Verification Test Suite (35 Invariants)

pytest -v tests/

Verifies 35 automated invariants: lack of lookahead leakage, cost matrix arithmetic, Population Stability Index (PSI) drift detection, 80% four-fifths fairness rule, Shapley efficiency properties, and sub-10ms inference SLAs.
